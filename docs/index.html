Documentación Oficial

Bienvenido a la documentación oficial de Nebula OS. Aquí encontrarás toda la información teórica y técnica del sistema.

Nota del Equipo: NebulaOS fue diseñado desde cero pensando en el usuario moderno: desarrolladores y gamers que necesitan exprimir al máximo su hardware sin lidiar con procesos ocultos o falta de privacidad.

Requisitos del Sistema

Nebula OS está optimizado para consumir lo mínimo indispensable, pero para disfrutar del Modo Juego y el Nebula Designer con efectos 3D, sugerimos cumplir los recomendados.

  • Mínimos: Procesador Dual Core 2 GHz, 4 GB RAM, 25 GB Almacenamiento, GPU compatible con OpenGL 2.1.
  • Recomendados: Procesador Core i3 / Ryzen 3 o superior, 8 GB RAM, 50 GB SSD, GPU compatible con OpenGL 3.3.

Proceso de Instalación

Nuestra filosofía es que "poderoso no significa difícil". El instalador gráfico Calamares te guiará paso a paso:

  • Selección de idioma y distribución de teclado.
  • Conexión a red WiFi/Ethernet para descargar parches críticos durante la instalación.
  • Particionado automático o manual (recomendado cifrado LUKS).
  • Creación de usuario maestro.

Enfoque de Seguridad (Nebula Shield)

El módulo Nebula Shield funciona a nivel del kernel para proveer:

  • Antivirus y Firewall: Bloqueo proactivo de conexiones entrantes no autorizadas.
  • VPN Nativa: Enrutamiento opcional de tu tráfico para máxima privacidad.
  • Sandbox: Las aplicaciones privativas se ejecutan en contenedores aislados que no pueden acceder a tus archivos personales sin tu permiso explícito.

Licencias y Legalidad

Utilizamos un modelo de licencia dual para asegurar el crecimiento del ecosistema:

  • El Kernel y el Sistema Base operan bajo la licencia GNU GPL v3. Esto garantiza que el corazón de NebulaOS siempre será libre, auditable y sin puertas traseras.
  • Aplicaciones Propias (Nebula Store, Nova AI) operan bajo licencia MIT, fomentando que empresas de software de terceros porten sus juegos y herramientas a nuestra plataforma sin restricciones agresivas.
